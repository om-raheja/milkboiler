# milkboiler

This repo contains the CAD file and the PCB semantics as well as the source code for the ESP32 controller for the machine.

Have you ever desired for a cup of chai or some milk to make yogurt when you boil the milk too long and it overflows? MilkBoiler automatically turns off the stove when your milk is about to overflow, requiring no human intervention when boiling milk! 

Just clamp on MilkBoiler onto your pot turn up the stove and add some milk and you're good to go!
